# Agência Olivia - Front-end estático

Este projeto funciona como um site front-end puro com Vite + React.

## Como rodar

1. Instale as dependências:
   - `npm install`
2. Rode em desenvolvimento:
   - `npm run dev`
3. Gere a build:
   - `npm run build`

## Onde editar o conteúdo dos agentes

Os cards da home e as páginas de demonstração usam dados locais em:

- `src/data/agents.js`

Se quiser trocar textos, slugs, categorias ou mensagens de prévia, basta editar esse arquivo.

## Deploy

O projeto pode ser hospedado em qualquer provedor de sites estáticos ou aplicações front-end.
